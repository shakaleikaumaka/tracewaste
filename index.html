🏜️ THE PROVING GROUND

Trace was born in a real Burning Man camp kitchen — the Terrible Turtles Camp — working alongside a veteran high-volume chef, Chef Marcus. Temporary kitchens, shifting headcounts, big purchases, little storage, brutal teardown deadlines: if a food-loop agent can make good calls there, it can make them anywhere.

Leave No Trace is Burning Man's 9th principle. Trace is named for it. The mission is the principle turned into software: predict surplus before teardown, move useful food between camps, and get the rest into refrigerated recovery — so edible food never becomes waste in the first place. The same loop scales past the playa: restaurants, caterers, campuses, festivals — anywhere food moves in volume.
